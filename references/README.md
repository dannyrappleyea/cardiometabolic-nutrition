# References

- `sources/<id>.yaml` — one file per source (template: `templates/source.yaml`; schema: `schemas/source.schema.json`). Cited from topics as `[@id]`.
- `authorities.yaml` — organizations whose guidance is weighed, with jurisdiction, for the corroboration rule (METHODS §3).

Rules: IDs are stable and never reused; never delete a source, mark it `superseded`; record how and when each source was verified; findings are paraphrased with a locator. `reviewer_read` is set only by the human reviewer.
